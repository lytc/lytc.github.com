What the product makes possible

Digication’s ePortfolio product supports multimedia authoring, templates, sharing, and feedback. Kora connects learning work with courses and assignments. These are connected experiences supported by several applications and services.

My contribution

I have been a major contributor to the React frontend and backend over the product’s history. My work includes ePortfolio and course interfaces, content workflows, file management, and the API behavior those experiences depend on.

I built the initial content-repository application and continued working on its behavior and integration with the wider frontend. I also contributed to shared UI and data-access packages used across the product.

Engineering across the boundary

The work connects interactive React interfaces to typed GraphQL clients, service logic, relational data, and deployment. It includes developing new behavior and helping existing features move to newer services.

My contribution history starts in March 2011. TypeScript backend and React frontend work date from 2016; those are the center of how I build today. Earlier PHP work provides context for the legacy systems I have helped modernize.

A long-term responsibility

A product accumulates both capabilities and decisions. I work on the new feature and the surrounding contracts: how data is represented, how the interface uses it, and how changes fit into the existing application. Colleagues share in designing, implementing, reviewing, and operating the product.
